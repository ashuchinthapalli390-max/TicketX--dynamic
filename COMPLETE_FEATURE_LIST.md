🚀 WORKFLOW EXAMPLES
═══════════════════════════════════════════════════════════════════════════════

BOOKING A MOVIE:
1. Click "🎬 Movies" in navbar
2. Filter by city and date
3. Click "Search Movies"
4. Select a movie, click "Book Now"
5. Choose seats and time
6. Add to cart
7. Proceed to checkout
8. Confirm booking
9. Receive QR code

BOOKING AN EVENT:
1. Click "🎤 Events" or scroll to events section
2. Filter by location, category, price
3. Search for specific event
4. Click "Book Now"
5. Login if needed (auto-redirect)
6. Select number of tickets
7. Proceed to checkout
8. Confirm and get confirmation

BOOKING A HALL:
1. Browse events page
2. Filter for hall category (Functional, Conventional, Meeting)
3. Check availability and capacity
4. Click "Book Now"
5. Select date and time
6. Review amenities
7. Complete booking
8. Get confirmation with details

MANAGING ACCOUNT:
1. Login with credentials
2. Click dashboard button in navbar
3. Navigate tabs:
   - Dashboard: View statistics
   - Bookings: See history
   - Tickets: View QR codes
   - Profile: Update info
   - Locations: Save cities
   - Security: Change password

CHANGING PASSWORD:
1. Go to Dashboard
2. Click "🔐 Security" tab
3. Enter current password
4. Enter new password (6+ chars)
5. Confirm new password
6. Click "Change Password"
7. Success message appears
8. Re-login required on next session
